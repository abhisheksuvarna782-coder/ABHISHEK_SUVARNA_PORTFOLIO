# Abhishek Suvarna — AI & ML Engineering Portfolio

> Personal portfolio and interactive 3D engineering showcase for **Abhishek Suvarna**, an AI & ML engineering student and software developer from India.

---

## ✦ Key Highlights

- **Luxury Editorial Light Aesthetic**: Custom-tailored typography (`Instrument Serif`, `Manrope`, `JetBrains Mono`), muted olive & warm bronze color harmony, and magazine-grade grid layout.
- **Interactive 3D Crystalline Sculpture**: Scroll-driven Three.js sculpture with physical facet materials, counter-rotating inner neural core, orbiting satellites, and interactive cursor lighting.
- **Interactive 3D Card Tilt**: Physical card depth with perspective tilt, dynamic specular glare tracking, and elevated Z-axis content layers.
- **Interactive 3D Signal Beacon & Sliding Marquee**: 3D dodecahedron beacon in the Contact section that responds to pointer tracking and pulses when copying email.
- **Comprehensive Project Case Studies**: Deep architecture, impact metrics, technical highlights, and modals for DeepShield, RouteRecover AI, CyberGuard X, HealVision, and more.
- **Production Performance**: Zero build errors, strict type safety, zero lint warnings with Oxlint, and code-split 3D chunks.

---

## 🛠️ Tech Stack

- **Core**: React 19, TypeScript, Vite
- **3D & Graphics**: Three.js
- **Icons**: Lucide React
- **Styling**: Vanilla CSS (CSS variables, fluid typography, GPU-accelerated transforms)
- **Tooling**: Oxlint

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/abhisheksuvarna782-coder/ABHISHEK_SUVARNA_PORTFOLIO.git

# Navigate to project directory
cd ABHISHEK_SUVARNA_PORTFOLIO

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
# Type check and build bundle
npm run build

# Preview build locally
npm run preview
```

### Linting

```bash
npm run lint
```
